# Output Formats

Read this file when producing a literature map, debate table, or search handoff.

## Literature Matrix

| Year | Author | Work | Type | Debate role | Core position | Key concepts | Evidence state | DOI / stable source | Access / follow-up |
|---:|---|---|---|---|---|---|---|---|---|

Use one row per work. Link revised editions or translations in the access/follow-up cell.

## Position Comparison

| Scholar or school | Direct participant? | Object of analysis | Central claim | What it rejects | Player / reader role | Method | Best-supported source | Confidence |
|---|---|---|---|---|---|---|---|---|

Avoid forcing a binary label when a scholar changes position or works at a different analytical level.

## Evidence States

| State | Meaning | Permitted use |
|---|---|---|
| Discovered | Search result or unverified mention | Reading queue only |
| Bibliographically verified | Metadata confirmed by publisher, journal, DOI, repository, or library | Bibliography and chronology |
| Abstract-verified | Abstract supports relevance or a broad claim | Cautious high-level summary labeled as abstract-level |
| Full-text verified | Claim supported by the work itself | Position summary with page, section, or paragraph locator |
| Secondary-only | Another scholar attributes the claim | Historiographic context plus explicit follow-up flag |

## Compact Search Log

| Query / trail | Source or index | Date searched | Useful results | Exclusions | Next branch |
|---|---|---|---|---|---|

Record enough detail to resume the search; do not dump every failed query.

## Reading Priority

Group works as:

1. **Core** — directly answers the research question or defines the debate.
2. **Method** — supplies concepts or analytic tools.
3. **Context** — explains disciplinary or historical background.
4. **Revision** — corrects, contests, or updates the canonical framing.
5. **Follow-up** — relevant but not yet verified or accessible.
